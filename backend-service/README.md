# Функциональность dashboard

## Загрузить данные 

Открывается модальное окно для загрузки файла.

## Результаты

Открывается новая страница с результатами, в которой будут:
Фото галактики, график квантильной регрессии и 
результат регрессии. 

## Модели

Открывается модальное окно с выбором модели. Модели берутся 
из БД списком. После смены модели страница перезагружается
