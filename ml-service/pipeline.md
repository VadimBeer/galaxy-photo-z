1. сообщение принимается с java
2. обрабатывается это сообщение и парсится в соответствующий 
объект
3. берется путь файла из объекта и скачивается файл
4. происходит предобработка файла 
5. файл закидывается в модель
6. модель выдает результат квантилей 
7. модель строит график
8. Сохранить график в MinIO
9. генерируется ответ в виде соответствующего объект
10. Реализовать передачу статуса
11. ml service отправляет созданный объект на java сторону
